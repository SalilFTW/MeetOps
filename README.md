# MeetOps

MeetOps is an Executive Productivity Agent.

## Assignment

Assignment 1 — Executive Productivity Agent

## Goal

MeetOps converts messy executive inputs into a useful daily action brief.

## Core Capabilities

- Identify executive commitments
- Separate my actions from waiting on others
- Detect deadlines and overdue items
- Deduplicate actions across sources
- Flag unclear ownership
- Generate a daily brief
- Answer questions about commitments and actions
